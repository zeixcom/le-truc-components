### Basic Pluralize

A locale-aware pluralisation component driven by `Intl.PluralRules`. Demonstrates `asClampedInteger()` to clamp the count to a non-negative integer, `bindVisible()` for conditional visibility, and `bindText()` for the count display. The factory attaches `watch()` calls dynamically — only for the plural categories that the given locale actually uses — guarding each optional descendant with `if (element)`.

Effects for `.count`, `.none`, and `.some` are always attached. Effects for the plural category classes (`.zero`, `.one`, `.two`, `.few`, `.many`, `.other`) are only attached for the categories supported by the active locale — for example English only uses `one` and `other` for cardinal, and `one`, `two`, `few`, `other` for ordinal.
