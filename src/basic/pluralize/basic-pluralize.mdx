### Basic Pluralize

A locale-aware pluralization component built on `Intl.PluralRules`. It demonstrates wiring up only the plural-category elements a given locale actually needs, rather than all of them unconditionally.

#### Tag Name

`basic-pluralize`

#### Descendant Elements

All descendant elements are optional — each is guarded with `if (element)` before its effect is attached.

Effects for `.count`, `.none`, and `.some` are always attached. Effects for the plural category classes (`.zero`, `.one`, `.two`, `.few`, `.many`, `.other`) are only attached for the categories supported by the active locale — for example English only uses `one` and `other` for cardinal, and `one`, `two`, `few`, `other` for ordinal.
