### Basic Counter

The canonical introductory example for Le Truc. Demonstrates applying `asInteger()` directly to a descendant's text content to initialize a reactive property from existing DOM content rather than an attribute, `on('click')` to update `host.count` imperatively, and `bindText()` to keep the display in sync.
