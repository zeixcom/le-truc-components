### Card Blogmeta

A static date-formatting component that runs once at connect time. Reads `dateTime` from descendant `<time>` elements and replaces their text content with locale-aware long-form dates using `Intl.DateTimeFormat`. If the modification date is invalid, the surrounding `<span.modified>` is removed entirely. No reactive props — all work is imperative and completes before the first paint.
