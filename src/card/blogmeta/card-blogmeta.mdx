### Card Blogmeta

A component that displays blogpost meta information: author, published date, optional modified date, and read time. The markup is annotated with [schema.org](https://schema.org/BlogPosting) `author` (`Person`), `datePublished`, `dateModified`, and `timeRequired` properties for search engines and other structured-data consumers.

If no avatar image is provided, a stylized placeholder avatar is shown instead — see the `WithoutAvatar` story.
