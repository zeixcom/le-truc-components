### Card Mediaqueries

A demo card that displays live media query values received from a `context-media` provider. It shows how a context consumer falls back to a default value when no provider is present, then updates reactively once one connects.

#### Tag Name

`card-mediaqueries`

#### Context Provider

Wrap with `context-media` to receive live media query values. Without it, all properties show `"unknown"`.

```html
<context-media>
  <card-mediaqueries>
    <dl>
      <dt>Theme:</dt><dd class="theme"></dd>
      <dt>Viewport:</dt><dd class="viewport"></dd>
    </dl>
  </card-mediaqueries>
</context-media>
```
