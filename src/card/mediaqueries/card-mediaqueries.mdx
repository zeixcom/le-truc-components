### Card Mediaqueries

A demo card that displays live media query values received via context. Demonstrates `requestContext()` — properties are initialised to a fallback value (`"unknown"`) when no `context-media` ancestor is present, and automatically updated when one is. The four context keys are provided by the `context-media` component.

#### Tag Name

`card-mediaqueries`

#### Context Provider

Wrap with `context-media` to receive live media query values. Without it, all properties show `"unknown"`.

```html
<context-media>
  <card-mediaqueries>
    <dl>
      <dt>Theme:</dt><dd class="theme"></dd>
      <dt>Viewport:</dt><dd class="viewport"></dd>
    </dl>
  </card-mediaqueries>
</context-media>
```
