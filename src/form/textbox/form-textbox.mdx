### Form Textbox

A general-purpose text field wrapper for `input` or `textarea` elements. Sets the `:state(clearable)` custom state when a `button.clear` descendant is present, so CSS can reserve space for it. Demonstrates a private `createState()` signal (`length`) updated via `on(textbox, 'input', ...)` and exposed read-only as `length.get`, a conditional `createMemo()` for `description` that produces either a static string or a computed remaining-characters string depending on DOM attributes, `defineMethod()` for the `clear` method, and the shared `relayValidity()` helper that mirrors the native input's `checkValidity()`/`validationMessage` into both the inline `.error` element and `host.setCustomValidity()`. Form participation and validity are via ElementInternals (`formAssociated()`) — external consumers read `host.validity`/`host.validationMessage` like on a native input; there is no separate `error` reactive property, and no manual `aria-invalid`/`aria-errormessage` — native `:invalid`/`:user-invalid` and ElementInternals validity replace them. Designed to be composable — `form-combobox` and `module-todo` both embed it and drive it via `pass()`.
