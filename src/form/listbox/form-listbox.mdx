### Form Listbox

A full-featured listbox with client-side filtering and optional remote option loading. Demonstrates `createElementsMemo()` used directly as a property initializer to create a reactive live collection of visible options, `createTask()` for async JSON fetching with abort support (via `nil`/`ok`/`err` handlers passed to `watch()`), `schedule()` to batch the fetched-HTML write into the listbox, and `each(options, ...)` for per-option reactive effects (filter matching/highlighting, selection state). Roving-tabindex keyboard navigation (Arrow/Home/End) is implemented inline via `on(listbox, 'keydown'/'keyup'/'click', ...)`. Form participation and value sync are via ElementInternals (`formAssociated()`) — set `name` directly on `<form-listbox>`; no hidden input descendant is needed. The `options` reactive property is a `Memo<HTMLButtonElement[]>` that tracks only currently visible (non-hidden) options.
