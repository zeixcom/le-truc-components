### Form Inplace Edit

An inline text editor that toggles between a read-only label and an editable `<form-textbox>`. Demonstrates `asBoolean()` for the `editing` attribute, dynamic DOM construction inside a `watch()` handler (creating and inserting a `<form-textbox>` on enter, removing it on exit), and focus management. The edit button, double-click on the label, Enter, and Escape all control the editing state.
