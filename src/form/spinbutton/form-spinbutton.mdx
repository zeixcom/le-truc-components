### Form Spinbutton

A quantity spinbutton with increment/decrement buttons, clamped values, and keyboard support. It works both controlled and uncontrolled, and participates in forms just like a native input. A fractional `step` attribute switches the whole component to floating-point mode (`value`/`min`/`max` parsed and rounded as decimals instead of integers), and negative ranges are supported.

#### Keyboard Support

Arrow Up/Down step the value by one `step` (Shift for `big-step`) regardless of which control has focus. `+`/`-` do the same, but only when a button has focus — when the input itself is focused, `+`/`-` are left to the browser's native text entry so a negative value can be typed directly (e.g. `-5`) when `min` is below `0`.
