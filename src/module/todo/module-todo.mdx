### Module Todo

A full-featured to-do list orchestrator. Uses `createList()` with per-item `createStore()` signals and `reconcile()` to sync a keyed list of todo items to the `<ol data-container>`/`<template>` pair, and `createMemo()` to derive reactive `activeCount`/`completedCount` from the list. Demonstrates `pass()` with `{ get, set }` descriptors to mediate each rendered `form-checkbox`'s `checked` prop to its matching item's `Store`, `pass()` with thunks to push `disabled`/`badge`/`count` into child components, `bindAttribute('filter')` on the host to drive CSS-based filtering, and event delegation on the host for item removal. Relies on `form-textbox`, `basic-button`, `form-checkbox`, `basic-pluralize`, and `form-radiogroup` as descendant components.
