### Module Listnav

A navigation coordinator that syncs `form-listbox` selection with `module-lazyload` and the browser's location hash. Uses `pass()` to reactively push `listbox.value` as the `src` of the lazyload. Uses `createEffect` to write `location.hash` when the selection changes, and a `hashchange` listener to update the listbox when the user navigates with the browser back/forward buttons.

#### Tag Name

`module-listnav`

None. This component coordinates child component properties through effects.
