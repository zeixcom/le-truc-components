### Module Color Info

A color information panel that displays a color's name, swatch, and format conversions (CSS Oklch, HEX, RGB, HSL). Demonstrates multiple derived readonly props via `MemoCallback`, `bindStyle()` for the swatch CSS custom properties, `pass()` to drive a collection of `<basic-number>` children via `all()`, and `bindText()` for the format string elements.

#### Tag Name

`module-colorinfo`
