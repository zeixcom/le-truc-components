### Module Calctable

An editable calculation table — description, amount, and price/unit columns compute a per-row price, plus running totals in the footer.

#### Tag Name

`module-calctable`

#### Preview

<Canvas of={ModuleCalctableStories.Default} />

#### Reactive Properties

None. This component owns its data internally via `createList()` and drives the DOM directly.

#### Row Structure

Each item row (server-rendered or cloned from `<template>`) needs three inputs identified by class, plus an element with class `price` for the computed value:

<table>
  <thead>
    <tr>
      <th>Selector</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>input.description</code></td>
      <td>Free-text item description</td>
    </tr>
    <tr>
      <td><code>input.amount</code></td>
      <td>Integer amount, clamped to <code>[0, 100]</code>; setting it to <code>0</code> on an existing row removes the row</td>
    </tr>
    <tr>
      <td><code>input.price-per-unit</code></td>
      <td>Price per unit, clamped to <code>[0, 1000]</code>, 2 decimal digits</td>
    </tr>
    <tr>
      <td><code>.price</code></td>
      <td>Read-only computed cell; text content is set to <code>amount × pricePerUnit</code>, formatted with the configured <code>Intl.NumberFormat</code> options</td>
    </tr>
  </tbody>
</table>
