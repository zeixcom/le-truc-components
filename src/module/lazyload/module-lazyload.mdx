### Module Lazyload

Fetches and injects remote HTML content into the page. Uses `createTask` to manage async fetch state (pending, success, error) reactively. Demonstrates `dangerouslySetInnerHTML()` for injecting fetched HTML, `show()` to switch between loading/error/content states, and `toggleClass('danger')` on the callout. The `allow-scripts` attribute opts in to executing inline scripts in loaded content.
