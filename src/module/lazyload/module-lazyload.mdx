### Module Lazyload

Fetches and injects remote HTML content into the page. Uses `createTask` to manage async fetch state reactively, with `watch(content, { ok, nil, stale, err })` branching on the task's `SingleMatchHandlers` to switch between loading/error/content states — each branch imperatively toggles `hidden` and returns a cleanup function where needed. Demonstrates `dangerouslyBindInnerHTML()` for injecting fetched HTML and `schedule()` to defer a smooth scroll-to-heading after a non-initial load. The `allow-scripts` attribute opts in to executing inline scripts in loaded content.
