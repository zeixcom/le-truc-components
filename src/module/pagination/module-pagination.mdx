### Module Pagination

A pagination control with previous/next buttons and a number input. Both `value` and `max` are read from the DOM input element via `read()` with `asInteger()`. Demonstrates `setAttribute` to reflect `value` and `max` onto the host element, `setProperty` to drive the input and button `disabled` states reactively, and keyboard shortcuts (Arrow keys, `+`/`-`) via `on('keyup')` on the host. The component hides itself when `max` is 1 or less via `show()`.
