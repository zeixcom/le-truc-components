### Module List

A dynamic list with add and delete functionality. Exposes `add(process?)` and `delete(key)` as reactive methods via `asMethod()`. The `add` method clones the `<template>`, assigns a `data-key`, optionally processes the item, and appends it to the container. Delete buttons are handled via event delegation on the host. A `max` attribute limits the number of items; the add button is disabled at the limit.
