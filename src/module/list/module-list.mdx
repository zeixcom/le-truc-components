### Module List

A dynamic list component that owns its data and keeps the DOM in sync via keyed reconciliation. It's the reference example for adding, removing, and reordering items without losing element identity.

#### Tag Name

`module-list`

#### Preview

<Canvas of={ModuleListStories.Default} />

#### Reactive Properties

None. This component owns its list data internally via `createList()` and coordinates descendant components through effects.
