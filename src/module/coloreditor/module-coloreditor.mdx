### Module Color Editor

An orchestrator component that wires together a `<form-textbox>` for the color name, a `<form-colorgraph>` color picker, a `<card-colorscale>` preview, and a series of `<module-colorinfo>` panels for base and derived shades. Demonstrates `pass()` to share signals across multiple child components, derived readonly props via `MemoCallback`, and `on(host, 'change', ...)` to capture name edits from a bubbled input event.
