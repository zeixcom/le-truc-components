### Module Tabgroup

An accessible tab group with keyboard navigation. Uses a private `createState` (read from the DOM at connect time) updated from both `on('click')` and `on('keyup')` (ArrowLeft/Right/Up/Down, Home, End) handlers on `all('button[role="tab"]')`, exposing it read-only via `expose({ selected: selectedState.get })` so consumers cannot set it directly. Demonstrates a `watch('selected', ...)` custom handler that imperatively updates `ariaSelected`/`tabIndex` on the tabs and `hidden` on `all('[role="tabpanel"]')`.
