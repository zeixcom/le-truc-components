### Module Ticker

A high-throughput live data table demonstrating virtualization with `IntersectionObserver` and fine-grained reactivity with `createList`. Each row's price, change, and volume are independent `State<TickerItem>` signals — only materialized rows have active `watch()` effects, so updating off-screen rows is cheap. `each(rows, ...)` wires and tears down per-row effects automatically as rows materialize and virtualize.
